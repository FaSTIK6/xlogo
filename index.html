Command Reference

Origin (0, 0) is at the center of the canvas. The Y axis points up. Heading 0 points up, 90 points to the right. Commands are case-insensitive.

Movement

FD n, FORWARD nMove forward n steps
BK n, BACK nMove back n steps
RT a, LT aTurn right / left by a degrees
HOMEMove to (0,0) and set heading to 0
SETX x, SETY yMove to the given coordinate
SETXY x yMove to (x, y)
SETHEADING aSet absolute heading

Pen & Colors

PU / PDPen up / pen down
PE / PPTEraser / draw again
SETPW nSet pen width (default 2)
SETPC colorSet pen color
SETSC colorSet background color
CS, CLEARSCREENClear screen and return home
WASHClear screen keeping position

Colors can be given by name (red, blue, green...), palette number 0–15, RGB list [255 128 0], or HEX #ff8000.

Control

REPEAT n [ … ]Repeat n times (REPCOUNT is the iteration number)
IF condition [ … ]Run if condition is true
IFELSE condition [ … ] [ … ]Run one of two blocks
MAKE "name valueAssign a variable, access with :name
TO name :param … ENDDefine a procedure
STOPExit a procedure
PRINT valuePrint to the Output panel

Expressions

+ − * /, comparisons = < > <= >= <>, parentheses, AND, OR, NOT. Functions: SUM, DIFFERENCE, PRODUCT, QUOTIENT, SQRT, ABS, ROUND, INT, RANDOM n, SIN, COS, TAN, XCOR, YCOR, HEADING, PI, COUNT.

Example

to square :size
  repeat 4 [ fd :size rt 90 ]
end
